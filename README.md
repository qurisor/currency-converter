# Currency Converter

Десктопное приложение на Python для конвертации валют и анализа изменения курса за период. Получает актуальные и исторические курсы из нескольких внешних источников с автоматическим переключением между ними (fallback).

## Возможности

- **Multi Converter** — конвертация одной базовой валюты сразу в несколько выбранных.
- **% Change** — расчёт процентного изменения курса за 7 / 30 / 90 дней.
- Интеграция трёх источников курсов с системой fallback (если один недоступен — запрос идёт к следующему):
  - Frankfurter API
  - ExchangeRate-API (open.er-api.com)
  - RSS Национального Банка РК
- Разбор ответов в форматах **JSON** и **XML**.
- Обработка валют, отсутствующих в API, через собственные константы.
- Кэширование запросов и обратный поиск по датам (если на конкретный день данных нет).
- Флаги стран рядом с валютами.
- Экспорт результатов в **CSV**.
- Многопоточность — интерфейс не зависает во время запросов к API.

## Стек

- Python 3
- Tkinter — графический интерфейс
- requests — HTTP-запросы
- Pillow — обработка изображений флагов
- xml.etree.ElementTree, csv — стандартная библиотека

## Установка и запуск

1. Установить зависимости:
   ```bash
   pip install requests Pillow
   ```
   > tkinter обычно поставляется вместе с Python. На Linux при необходимости: `sudo apt install python3-tk`

2. Запустить приложение:
   ```bash
   python main.py
   ```

## Структура

Весь код находится в файле `www.py`:
- функции получения курсов и логика выбора источника (`get_rate`, `get_rate_nbrk`, `get_rate_frank` и др.);
- класс `CurrencyApp` — графический интерфейс на Tkinter с двумя вкладками.
